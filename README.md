## Entry

> Hey boss, can't come in today — slept on my neck wrong and now I can only turn left, so I'd have to drive here in circles.

## How it works

`main.ts` is a deterministic program (no network, no randomness, no time/date). It writes exactly one line — the sick-day excuse above — to `/output/entry.txt`.
